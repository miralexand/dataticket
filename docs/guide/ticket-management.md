# 工单管理

工单管理是系统的核心功能，提供完整的工单生命周期管理。

## 创建工单

访问 `/tickets/create` 页面，填写以下信息：

- **工单标题**（必填）- 简短描述问题
- **工单描述**（必填）- 详细说明问题情况
- **工单类型** - 日常维护、技术支持、财务问题、功能请求、故障报告、其他
- **优先级** - 低、中、高、紧急
- **申请科室**（必填）- 选择所属科室
- **联系电话**（可选）
- **位置/房间号**（可选）
- **紧急说明**（可选）

## 工单列表

访问 `/tickets` 查看所有工单，支持：

- **状态筛选** - 待处理、处理中、已解决、已关闭
- **搜索功能** - 按标题、描述、编号搜索
- **排序** - 按优先级、状态、创建时间排序

## 工单详情

点击工单列表中的任意工单，查看详细信息和状态历史，包括：

- 工单基本信息
- 处理信息（处理人、处理结果）
- 时间线（创建、更新、关闭记录）

## 状态流转

工单状态遵循以下流转规则：

```
待处理 → 处理中 → 已解决 → 已关闭
```

::: tip 提示
只有创建者、处理人或管理员可以编辑工单。
:::
