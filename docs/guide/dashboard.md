# 数据看板

数据看板是系统的首页，提供工单数据的可视化展示和实时监控。

## 功能特性

### 时间范围筛选

支持多种时间范围查看：

- **快速选择** - 本周、本月、本季度
- **按月份** - 选择具体月份
- **全部** - 查看所有历史数据

### 核心统计

看板顶部展示核心指标卡片：

| 指标 | 说明 |
|------|------|
| 总工单数 | 当前范围内的工单总数 |
| 待处理 | 状态为"待处理"的工单数 |
| 处理中 | 状态为"处理中"的工单数 |
| 已解决 | 状态为"已解决"或"已关闭"的工单数 |

### 图表展示

- **工单趋势图** - 展示工单创建和解决的趋势
- **分类分布** - 按工单类型统计
- **优先级分布** - 按优先级统计
- **科室分布** - 按申请科室统计

### 最新工单

展示最近创建的 10 条工单，包含状态、优先级、标题、科室、登记人、处理人和创建时间。

## 自动刷新

看板支持自动刷新功能：

- 默认关闭，可手动开启
- 开启后每 60 秒自动刷新数据
- 支持手动点击刷新按钮

## 看板模式

系统支持免登录的看板模式，配置 `dashboardConfig.enabled = true` 后，系统会自动使用配置的账号登录并跳转到看板页面，适用于公共展示场景。
